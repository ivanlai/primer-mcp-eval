I have regular payments like rent. `expenses recurring add AMOUNT CATEGORY --day N` should record a monthly recurring expense on day N (with an optional `--note`), and `expenses recurring list` should show them. `expenses recurring apply YYYY-MM` should add that month's recurring expenses as ordinary expenses. Applying the same month twice must not add them twice, and a day that a month does not have (such as 31 in February) should fall on the last day of that month.
