        ## What
        Run the whole task set once in each arm (24 runs) as a dress rehearsal. Prove the pipeline works end to end, measure the real cost per run, and hand-read transcripts to confirm the automatic checks count what they claim to.

        ## Acceptance Criteria
        - All 24 pilot runs finish and are scored, and none of them count toward the headline
- The isolation check passes for every baseline run
- A sample of transcripts from each arm is hand-read, and any disagreement with the automatic checks is fixed or written down
- The cost per run is measured and used to confirm the budget for the main run
