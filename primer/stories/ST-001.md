        ## What
        A small Python command-line app with a pytest suite, kept in this repo, that every run starts from. It is realistic enough to take multi-step features and refactors, contains planted bugs for the bug-fix tasks, and carries nothing primer-related, so both arms start from the same state.

        ## Acceptance Criteria
        - About 500-800 lines of Python with a passing pytest suite, apart from the planted bugs
- Planted bugs that match the three bug-fix tasks, each caught by a test that fails on the fixture as shipped
- No primer/, CLAUDE.md, AGENTS.md or planning documents in the fixture
- It lives in its own subdirectory, so copying it takes nothing from this repo's planning
