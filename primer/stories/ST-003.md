## What
A small runner that runs any task in either arm as an isolated headless Claude Code session and saves everything scoring needs. It also proves that the baseline arm really has no primer-mcp and none of the developer's user-level config.

## Acceptance Criteria
- One command runs a chosen set of tasks, arms and repetitions
- Each run uses a fresh copy of the fixture, a clean user config directory and --strict-mcp-config, and pins the CLI, model and primer-mcp versions
- The primer arm gets init_project applied at the pinned version; the baseline arm gets nothing
- Each run saves its stream-json transcript, final repo state and the versions it used
- A check fails the run if a baseline transcript shows primer tools or user-level instructions
- A per-run budget cap is enforced, and pilot output is stored apart from the headline runs
