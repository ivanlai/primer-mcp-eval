## Why
The headline compared baseline against primer-mcp's tools and CLAUDE.md instructions together, so it can't say whether the tools add anything. The strongest objection to primer-mcp is that a line in CLAUDE.md saying 'plan first' would have the same effect. This epic tests that directly.

## Goals
- Run a third arm that has only a one-line planning instruction and no primer-mcp
- Compare it with the baseline and primer arms on the headline metrics
- Report in the README whether the instruction alone closes the planning gap

## Constraints
- Same scenarios, prompts, checks, scoring rules and pins as the headline
- Reuse the headline baseline and primer runs; if the pins can't be restored, run only the new arm at new pins and state the version gap in the results

## Non-Goals
- A detailed tool-free instruction arm (a possible follow-up, depending on this result)
- New metrics or scenarios

## Success Criteria
- 36 instructions-arm runs isolated and scored at the same pins as the arms they're compared with
- The README states whether the one-line instruction matches primer-mcp on planning, and what that means for the objection
