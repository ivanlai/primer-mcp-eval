## Parent Epic
[[EP-002]]

## Context
ADR-006's arm put only 'Plan first.' in CLAUDE.md. It never asked for the plan to be saved, so scoring 0% on the written-plan and durable-record metrics was close to guaranteed, and comparing it with primer-mcp's record was not a fair test of the objection. Its runs showed the agent planning in chat, which ADR-004's deterministic metrics cannot score and which needs transcript reading to report.

## Decision
Replace the instructions arm's CLAUDE.md with the single line 'Plan first, and save the plan in docs/ before changing code.' Everything else follows ADR-006: no MCP servers, CLAUDE.md in the initial commit, 12 scenarios × 3 at the headline pins, ADR-004's rules unchanged, compared with the existing baseline and primer runs. The 'Plan first.' runs are superseded and not reported; the arm keeps its name.

## Alternatives Considered
- Keep 'Plan first.' and add this as a fourth arm: rejected because the one-liner's result was predictable from its wording, and reporting it adds reading without insight
- primer-mcp's CLAUDE.md section rewritten to use Markdown files instead of tools: rejected for now because it is no longer 'a line in CLAUDE.md'; it stays the follow-up if this arm matches primer-mcp
- Name the folder or file format (e.g. docs/plans/<topic>.md): rejected to keep the instruction as short as a user would write it

## Consequences
A plan file in docs/ written before the first code edit scores as a written plan and a durable record, the same as a primer ticket, so the arm can match primer-mcp on both metrics. If it does, primer-mcp's remaining value is the structure of its record (linked tickets, decisions, verification) and whether later sessions use it. If the agent often skips the file, that favours tools over instructions. Another 36 runs, about $10.
