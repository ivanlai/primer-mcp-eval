## Parent Epic
[[EP-001]]

## Context
The headline claim is that installing primer-mcp changes how an agent works, so the comparison needs an arm without it. There are two candidate baselines: no MCP at all, or primer-mcp's tools without its CLAUDE.md section. They answer different questions. The primer arm could also start before or after init_project. Headless runs (ADR-002) have no user, and the CLAUDE.md section tells the agent to propose a ticket and let the user decline. Left as it is, a primer-arm run may stop at a proposal and never do the work.

## Decision
Two arms, both on a fresh copy of the same fixture (ADR-001). Baseline: no MCP servers and no CLAUDE.md. Primer: a pinned primer-mcp over --mcp-config, with init_project already run on the fixture, so primer/ and the workflow section in CLAUDE.md and AGENTS.md are there from the start. Nothing else is seeded in the primer arm: no epics, stories or standing bug-fix story. Every task prompt in both arms ends with the same neutral line saying the agent should work autonomously because no one will answer questions. A run that stops to ask anyway is recorded as a behaviour, not retried.

## Alternatives Considered
- Tools without the CLAUDE.md section as the baseline: rejected for the headline because it measures only the effect of the instruction text, not of adopting primer-mcp. It is kept as a possible third arm (an ablation) if the headline shows an effect worth breaking down
- Three arms from the start, including tools-only: rejected for now because it adds 1.5 times the cost before we know there is an effect to break down
- A bare start where the agent must run init_project itself: rejected because it mixes in whether the agent adopts primer-mcp at all, a failure mode that has nothing to do with planning behaviour
- Natural prompts with no line about autonomy: rejected because primer-arm runs could end at a ticket proposal, so the result would mostly measure friction in headless use and not planning behaviour

## Consequences
The headline answers one question: does an agent in a project that has adopted primer-mcp behave differently from one with no primer-mcp at all? It cannot say how much of any effect comes from the tools and how much from the CLAUDE.md text. The autonomy line is a small, disclosed departure from natural use, and it applies equally to both arms. The primer arm starts with no standing bug-fix story, so how the agent parents bug fixes is part of what we observe. The fixture is kept in its baseline form, and the runner applies init_project at the pinned version for the primer arm, so the test app has a single source copy.
