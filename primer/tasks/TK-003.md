## What to do
Settle how a task is stored: one directory per task holding its prompt, functional check, expected file set and a reference solution. Also fix the wording of the shared autonomy line. Turn TK-002's bugs A-C into the first three tasks: symptom-only prompts, and the existing checks moved into their task directories.

## Testable Outcome

## Completion Notes
Task format in tasks/ (prompt, task.toml, check, reference patch; shared autonomy line) and the three bug-fix tasks

- Format is documented in tasks/README.md: one directory per task, recognised by its task.toml; prompt.md holds only the request, and the runner appends tasks/autonomy.txt after a blank line.
- Autonomy line (neutral wording, chosen with Ivan): "You are working on your own: no one is available to answer questions, so use your judgement and complete the task."
- The TK-002 checks moved from checks/ into their task directories. The reference patches restore the original code from git and are relative to the fixture root.
- expected_files lists source files only; tests/ is always in scope, and planning files are scored separately (ADR-004).

### Details
The checks share tasks/conftest.py, which sits outside the fixture copy's rootdir, so pytest must be run with --confcutdir=<repo>/tasks, or the `run` fixture is not found. For TK-007: treat only directories with a task.toml as tasks (pytest leaves a __pycache__ in tasks/). Because the autonomy line is appended by composition, the validator should check that autonomy.txt exists and that prompt.md avoids the banned words, rather than looking for the line inside each prompt.
