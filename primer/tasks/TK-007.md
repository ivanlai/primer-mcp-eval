## Parent Story
[[ST-002]]

## What to do
Add a small script that checks every task mechanically on a fresh copy of the fixture. For each task: the check fails before, the check and the shipped suite pass after the reference is applied, the reference diff stays within the expected file set, and the prompt ends with the autonomy line and never mentions primer, tickets or planning.

## Testable Outcome
One command validates every task present and reports pass or fail per task; the three bug-fix tasks pass, and later tasks are validated with it as they are added

## Dependencies
- [[TK-003]]

## Completion Notes
scripts/validate_tasks.py validates every task on a fresh fixture copy; the 3 bug tasks pass, and 4 broken tasks are each caught

- Run it with `python3 scripts/validate_tasks.py [task-id ...]`. It uses only the standard library and runs pytest through uv inside each copy. The three bug tasks take about 3 seconds.
- Per task it checks: required files, a valid kind, non-empty expected_files, banned words in the prompt, the check failing (not erroring) on the fixture as shipped, the reference applying, the check and the fixture suite passing with it, and the reference staying within expected_files plus tests/.
- The fixture comes from git HEAD, as it will for the runner, so fixture changes must be committed before validating.

### Details
Negative-tested with four deliberately broken tasks, created and then deleted: a check that passes before plus banned prompt words, a bad kind plus an out-of-scope reference, a patch that doesn't apply, and a check that errors. That first pass exposed two flaws, both fixed. It stopped at the first metadata problem, which hid later ones; now only missing files stop validation early. It also counted an erroring check as failing, because pytest exits 1 for both; it now reads pytest's JUnit XML to tell them apart, so a conftest that isn't loaded, like the --confcutdir problem in TK-003, reads as an error. The banned-word list (primer, ticket, plan, ADR, epic, commit, test) may need loosening if a real prompt uses one of them innocently.
