## What to do
An unauthenticated real-CLI probe (no cost) showed what a headless 2.1.283 session actually loads. Use it to (1) make the isolation check verify that no user-level skills, agents, plugins or memory reach a run, and (2) have scoring count a Task call to the Plan agent as planning, since headless mode lists no TodoWrite or TaskCreate. Record that plans written only as chat text are not counted.

## Testable Outcome
The isolation check fails a run whose init event lists a user skill or agent, a non-built-in plugin, or a memory path outside the run's HOME, and passes the real probe's init event. Scoring counts Task(subagent_type=Plan) before the first edit as planning. All script tests pass.

## Completion Notes
Isolation check now verifies no user skills, agents, plugins or memory reach a run; scoring counts the Plan agent as planning; 26 tests pass

- Probe: the real claude 2.1.283 was started with no credentials inside an empty HOME with the primer-arm MCP config. It stopped at "Not logged in" before any paid call, but its init event showed primer-mcp connected, auto-memory pointing inside the throwaway HOME, only built-in skills, agents and plugins, and no TodoWrite or TaskCreate in the headless tool list (Task with a built-in Plan agent, and ToolSearch, are present).
- run_eval.check_isolation now also fails a run if any of the developer's own skills (~/.claude/skills) or agents (~/.claude/agents) appear, a plugin isn't built-in, or a memory path lies outside the run's HOME. Against the real probe and the real ~/.claude, it reports isolated. The probe's init event is kept as test data (tests/init_event_2.1.283.json).
- score.py counts Task(subagent_type="Plan") before the first edit as planning. Its docstring now states that plans written only as chat text are not counted.

### Details
This replaces TK-008's caveat that the user-instructions half of isolation was only structural: the init event now shows directly what user-level configuration loaded. It still can't show whether ~/.claude/CLAUDE.md was read, but that file can't exist inside the empty HOME. The absence of a planning tool in headless mode means the baseline's in-session planning will mostly show as the Plan agent or not at all, so the pilot's hand-read sample should look for plans written only in chat, which the metric misses by definition.
