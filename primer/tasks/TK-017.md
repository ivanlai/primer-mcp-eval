## Completion Notes
- `scripts/export_inspect.py` converts each run's stream-json transcript into Inspect messages. All assistant events that share a message id merge into one message, even when tool results come between them. Tool results become tool messages; ToolSearch's tool_reference blocks show as tool names, and other non-text blocks as JSON. Empty thinking blocks are left out.
- Scores come from the frozen `results/<batch>/runs.csv`, so nothing is rescored. A metric that is blank (not applicable) gets no score on that sample.
- `inspect_ai` is pinned at 0.3.285 and used only by this script and its test. The test is skipped when the package is missing, so the standard-library test run is unchanged.
- A root `pyproject.toml` (no package, empty runtime dependencies) holds a dev group with pytest and `inspect_ai`, so `uv sync` creates `.venv` and `uv.lock` pins the versions. The run commands in the READMEs now use `uv run`.
- The logs are written to `results/<batch>/inspect/` and committed, because readers have no `runs/` to rebuild them from. The headline export gives 3 logs of 36 samples (about 1.1 MB in all). The per-arm rates equal summary.md.
- Each sample's start and end times are its first and last transcript timestamps; each log's are the earliest and latest of its runs, so the viewer header shows elapsed time, waits included.
- README: the Scoring table now names each measure's viewer column, and a "Browsing the runs" note explains C/I and why red isn't always bad.
