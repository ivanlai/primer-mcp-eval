Pilot: 24/24 runs clean and isolated on the Max plan; hand-read found 3 scoring flaws, all fixed and rescored; go for the headline

- Setup changes made to get real runs working: auth through a `claude setup-token` subscription token read from ~/.config/primer-mcp-eval/oauth-token (no API key, and Ivan's own login is never copied); the pinned 2.1.283 binary called directly with DISABLE_AUTOUPDATER=1, after `claude` auto-updated to 2.1.284 mid-day; `--redo-failed` to rerun failed runs.
- A serious isolation bug caught by the first real run: sessions ran inside runs/ within this repo, so an agent grepped parent directories (where the answer keys are), and Claude Code loads parent CLAUDE.md files, so the baseline probably saw this repo's primer section. Sessions now run under /tmp, and a run fails isolation if its cwd is in the repo or its transcript mentions the repo's path. The contaminated run was deleted and redone.
- All 24 runs exited 0 and passed isolation. Mean per run: baseline 18 turns, 62s, $0.28 estimated; primer 29 turns, 85s, $0.41. The most expensive was $0.73, so the $2 cap never bound (whether it is enforced on a subscription remains unseen). No usage limit was hit. The headline's 72 runs come to roughly 90 minutes and about $25 in API-equivalent cost.
- Pilot result (not the headline): planned first 0% vs 45%, durable record 0% vs 42%, verified 100% vs 100%, functional 100% vs 92%.
