# primer-mcp-eval

Does [primer-mcp](https://github.com/ivanlai/primer-mcp) change how AI coding agents work?

primer-mcp claims agents plan before they code when it is available: they state why the work matters, record decisions, break work into tasks, and verify what they finish. This repo measures whether that is true, by running an agent on the same coding tasks with and without primer-mcp and comparing what it does.

**Status:** planning. The evaluation design is tracked in `primer/` — see the epic and ADRs there for what is measured and why.
